# 🏧 ATM Simulator

Simulator ATM-i në C++ — krijim llogarie, kontroll bilanci, depozitë dhe tërheqje parash. Menu interaktive në terminal.

## 🚀 Si ta hapësh

Hap `index.html` — tab-i **Live Demo** ekzekutohet direkt në browser, ndërsa tab-i **Kodi Burim** tregon kodin e plotë.
